# Natrix Early Alpha v1.0.0

Natrix is currently in **alpha**, which means it is still under active development and may contain bugs, incomplete features, or breaking changes.

If you encounter a bug or unexpected behavior, please open an issue. If everything works as expected, even better!

## About

Natrix is a user-friendly **CLI environment manager** inspired by tools such as Conda and `venv`.

The project is built from scratch in **Rust**, with the goal of providing a lightweight and flexible environment management system.

Natrix currently focuses on Python environments, but its architecture is designed to eventually support multiple languages and ecosystems.

Rather than being limited to a single language or environment system, Natrix aims to provide a unified way to create, manage, and work with different development environments.

## Current Status

Natrix is in its early alpha stage.

The project is actively being developed, so features may change significantly between versions. Some functionality may be experimental or incomplete.
